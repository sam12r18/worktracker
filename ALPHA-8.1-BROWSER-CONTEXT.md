# WorkTracker Alpha 8.1 — Browser Context Integration

P0 introduces a Chrome Manifest V3 context bridge.

Core rule: **Chrome provides context; Windows Agent owns time.**

Scope: Chrome MV3 extension, explicit opt-in, URL privacy normalization, Incognito ignore, Native Messaging host, local Browser Context Bridge, SQLite/Sync/Laravel persistence and BrowserHost/BrowserPath/BrowserTitle project rules.

Not in P0: Chrome Web Store publication, Edge/Brave distribution, page-content inspection or server-direct extension sync.
