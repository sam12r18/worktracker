# WorkTracker 0.1.0-alpha.2 — Project Classification

Implemented:
- offline project creation
- UUID project/rule identities
- weighted deterministic project resolver connected to auto capture
- Unknown Activity Inbox
- manual project correction
- explicit Assign + Learn flow
- project selection for manual timers
- local rules view
- Laravel project CRUD bootstrap and sync support for project/project_rule

Time accounting remains additive. No overlap normalization is introduced.
